# ⚡ Linux Privilege Escalation Automation Toolkit

A professional-grade auditing framework designed for **OSCP** aspirants and **Cybersecurity Auditors**. This tool automates the detection of privilege escalation vectors on Linux systems.

## 🚀 Key Features
- **MITRE ATT&CK Mapping:** Every vulnerability is mapped to industry-standard techniques.
- **Risk Scoring:** Real-time risk assessment (0-100%).
- **Interactive Reports:** Generates clean HTML and JSON reports for auditors.
- **Deep Scan:** Checks for SUID, Cron Jobs, Capabilities, and Writable Files.
